# FrontEnd-DSW – ShoppingCart React

## 🛒 Descripción

**FrontEnd-DSW** es una aplicación web tipo *Shopping Cart* (carrito de compras) desarrollada con **React + TypeScript + Vite** como parte de la materia *Desarrollo de Software* (UTN FRRo).  
El proyecto consiste en una interfaz interactiva donde el usuario puede visualizar productos, agregarlos al carrito y ver el total acumulado, aplicando lógica de interacción y manejo de estados.

👉 Ver la demo en: https://front-end-dsw.vercel.app

---

## 🧰 Tecnologías usadas

Este proyecto fue desarrollado utilizando las siguientes herramientas y tecnologías:

- **React** – Librería de UI para construir interfaces de usuario.
- **TypeScript** – Tipado estático para JavaScript.
- **Vite** – Entorno de desarrollo frontend rápido.
- **CSS** – Estilos responsivos para presentación visual.
- **Git / GitHub** – Control de versiones y gestión del código.
